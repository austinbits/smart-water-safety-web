# Five-minute SIH demonstration

1. **Map and evidence (45 seconds):** Open Explore, switch among Calangute, Muthathi and Dudhsagar, select an original mapped path and play GPS replay. Open Data to show original hashes, corrected beach GPS, missing local river readings and preserved KML downloads.
2. **Forecast (45 seconds):** Show dataset replay, next 3/24 hours and one metric history. Refresh the current weather model; point out its source and retrieval time. Return to replay and choose Hazard spike to explain the transparent demo thresholds.
3. **Emergency workflow (90 seconds):** Start a high-zone drill. Let the 30-second timer finish, then open Rescue. Assign the same-site team, mark it on scene, send a demo zone message, and resolve. Return to Emergency to see the closure. The 112 dialler is for a real emergency and should not be called during a demo.
4. **Offline resilience (45 seconds):** Start another drill and enable Simulate no internet. Let its SOS enter the device queue. Restore connectivity and verify a single incident syncs. Open the same browser profile in another tab to show shared session updates. A separate profile creates an isolated workspace.
5. **Community and uncertainty (55 seconds):** Open Rescue → Path contributions. Load three synthetic traces, inspect/export them, accept each and export the resulting usage proposal. Explain that a field team must still verify it. Show a last-seen search envelope and how uncertainty grows with elapsed time.

Before presenting, visit all sites once online, save the offline bundle, and warm the Render backend. Device storage, browser GPS permissions and an initial successful online load are required for the relevant fallback features.

The strongest technical claims are reproducible source preservation, explicit provenance, correct spatial filtering, honest data gaps, shared deterministic routing/risk logic, isolated real-time demo sessions and idempotent SOS processing. Do not present generated records as real telemetry or claim official emergency integration.
